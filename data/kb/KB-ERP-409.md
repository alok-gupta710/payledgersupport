# ERP Sync Error ERP-409: Duplicate External ID
## What it means
ERP-409 means a record with the same external ID already exists in NetSuite or QuickBooks.

## How to fix it
1) Open Integrations > Sync Log and find the failed record. 2) In your ERP, search for the external ID shown. 3) Delete or merge the duplicate record in the ERP. 4) Click Retry sync. If the error persists after a retry, contact support with the sync log ID.
