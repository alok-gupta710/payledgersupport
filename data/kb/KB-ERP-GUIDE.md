# ERP Integration Guide
## Supported systems
PayLedger integrates with NetSuite and QuickBooks Online.

## Connecting an ERP
An admin opens Integrations, clicks Connect on the NetSuite or QuickBooks card, signs in to the ERP as an ERP admin and approves access.

## Sync schedule
Syncs run automatically every 30 minutes. An admin can start a sync at any time with Integrations > Sync now.

## Sync log
Every sync is recorded in Integrations > Sync Log with a sync log ID, the records synced and any error code. Error codes start with ERP- and each has its own troubleshooting article.
